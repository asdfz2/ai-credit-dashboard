# Trae 用量仪表盘增强

油猴脚本，为 Trae 个人版用量页面添加增强统计功能。

## 解决什么问题

Trae 官方用量管理页面只显示有限时间范围的数据，缺少：
- 总积分消耗统计
- 按模型维度的积分消耗 breakdown
- 近7天/本月等多维度统计
- 积分消耗趋势可视化

本脚本通过拦截页面 API 请求，自动获取所有分页历史数据，在页面上添加增强面板，满足个人版用户对用量统计的精细化需求。

## 主要功能

- **多维度积分统计**：总积分消耗、今日消耗、近7天消耗、本月消耗
- **按模型 breakdown**：显示每个模型消耗了多少积分、调用次数，条形图可视化对比
- **近7天消耗趋势**：柱状图显示每日积分消耗趋势
- **自动翻页获取全量历史**：自动拉取所有分页的历史数据，无需手动点击翻页
- **自动重试机制**：页面加载后自动检测数据，多种方式触发获取数据，保证不空白
- **SPA 适配**：监听 DOM 变化，防止页面路由切换后面板消失

## 安装方法

1. 需要浏览器安装用户脚本管理器：
   - [Tampermonkey](https://www.tampermonkey.net/)（推荐）
   - [ScriptCat](https://scriptcat.org/zh-CN)（开源替代）

2. 点击安装：
   [直接安装脚本](https://raw.githubusercontent.com/你的用户名/trae-dashboard-enhancer/main/trae-dashboard-enhancer.user.js)

   或者手动复制 `trae-dashboard-enhancer.user.js` 内容到脚本管理器新建脚本中保存。

## 使用方法

1. 安装脚本后，打开 [Trae 用量页面](https://www.trae.cn/dashboard#usage)
2. 脚本会自动拦截 API 请求并拉取所有历史数据
3. 在原页面内容上方会显示「📊 用量增强面板」
4. 如果没有数据，点击「刷新页面」按钮重新加载即可

**说明：**
- 数据存储在浏览器本地（GM_setValue），不会上传到任何服务器
- 自动翻页会延迟请求，避免给服务器造成压力
- 只做数据展示增强，不修改 Trae 任何服务器数据

### 数据来源

- 脚本从 Trae 页面已发起的 API 响应中提取数据
- 如果当前页面只有第一页数据，脚本会自动请求后续所有分页
- 认证由浏览器自动处理，无需用户配置 token
